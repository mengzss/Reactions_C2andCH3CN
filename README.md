# Reactions_C2andCH3CN
These files are Supplementary Data for "Gas-phase reactions between interstellar molecules C2 and CH3CN: insights from reactive molecular dynamics simulations".

The files include an example of the LAMMPS input script that was used in our study, along with the corresponding evolution trajectory files.

The file in the path "./LAMMPS_Example_Code/ " is used to simulate the reaction process between C2 and CH3CN, including the input script (in), input data (Datafile, potential_file) and output data (log, OUT, XYZ, XYZ2) of LAMMPS.

Then, the files in the path "./Evolution_Trajectory_Files/ " are the trajectory files of the evolution process of the 265 reactions we studied.
